Dent-Rメモ iPhoneホーム画面アプリ版 v0.6
========================================

重要：これはPWA（ホーム画面から起動するWebアプリ）です。
App Storeアプリ、ネイティブiOSアプリ、署名済みIPAではありません。

【既存データの保護・最優先】
1. 更新前にv0.5の「設定 → 全データを書き出す」でJSONをiPhoneの「ファイル」に保存。
2. 既存のGitHub Pagesリポジトリを使い、従来と完全に同じURL・同じフォルダへファイルを上書き。別リポジトリにしない。
3. インストール後、既存メモ件数を確認。見えない場合は削除・初期化せずバックアップから復元する。
4. Safari上とホーム画面Webアプリ間で保存領域が分離される可能性がある。既存メモが表示されない場合はバックアップをインポートする。
5. インストール後も定期的にJSONバックアップを「ファイル」アプリ等へ退避する。
※IndexedDBの名称・構造・バージョン、メモ・添付ファイルの保存ロジックはv0.5から変更していません。

【Windows PCから無料で配置する】
1. ZIPを展開する。
2. GitHubの既存のDent-Rメモ公開リポジトリを開く。
3. Add file → Upload filesで中身の index.html, record.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png を同じ階層へ上書きしCommit changes。
4. GitHubの Settings → Pages で公開URLを確認。新しいリポジトリを作る必要はありません。
5. HTTPS URLをiPhoneのSafariで開き、更新内容を確認する。

【iPhoneでアプリとしてホーム画面に設置する】
1. iPhoneのSafariで公開URLを開く（GitHub画面やZIPファイルではなく実際のアプリURL）。
2. Safariの共有メニュー → 「ホーム画面に追加」。
3. 表示される場合は「Webアプリとして開く」を有効にして「追加」。
4. ホーム画面に「Dent-Rメモ」アイコンができる。
5. アイコンから開き、メモを1件だけテストし、保存後も残っているか確認。

【録音直行アイコン（別途ショートカット）】
1. 公開URLが https://USERNAME.github.io/REPO/ の場合、録音URLは https://USERNAME.github.io/REPO/index.html?voice=1 。
2. iPhoneの「ショートカット」アプリで新規作成。
3. 「URL」アクションで録音URLを指定し、「URLを開く」アクションを追加。
4. ショートカット名を「Dent-R 録音」にして「ホーム画面に追加」。
5. アイコンをタップすると音声入力画面へ直行。
※iOSブラウザのマイク自動開始制限で、さらに「録音開始」タップが必要な場合があります。

【完全無料の条件と制約】
- 無料のGitHub Pagesと個人使用のPWAなら、公開・使用料金は原則不要。
- ローカルAIは未実装。音声認識はiOS/Safariの機能に依存し、通信が必要な場合があります。
- Webアプリはオフラインキャッシュがありますが、iOSの保存容量管理や初回読込、マイク機能を完全保証しません。
- URLを公開するとプログラムは公開されますが、端末に保存したメモ自体を自動公開する処理はありません。
- 患者氏名等の個人情報を音声で記録しないでください。
- App Store配布のiOSネイティブアプリを継続使用するには署名・配布条件が異なります。無料のPersonal Teamは7日ごとに再署名が必要です。

【動作チェック】
□ 旧版からのデータをバックアップ済み
□ 同じURLでv0.6が開く
□ ホーム画面のアイコンから開ける
□ 元の記録と添付ファイルが閲覧できる
□ 分類「歯科」、種類「タスク」の登録と保存が成功する
□ 「以上」で重複せず1件のみ追加される
□ データを書き出せる

v0.6変更点：iOSホーム画面向けメタ情報の強化、音声起動ショートカットをManifestに追加、キャッシュ更新、導入説明の刷新。v0.5の保存処理と画面機能は維持。
